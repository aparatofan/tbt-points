# TBT Points

Students earn points for the work they finish on The Blue Tree and exchange them for rewards (TBT merchandise, a book, a private lesson).

Built on TBT Notes' activity log (Notes 1.22.0+, the `tbt_notes_activity_recorded` action) — the same rows TBT Results shows.

- `docs/prototypes/points.html` — prototype: student page (balance, rewards, requests, history) and teacher page (Requests, Students, Rewards, Rules). Tablet and desktop only; no page header (Divi supplies it).

No plugin code yet.
